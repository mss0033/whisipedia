# ADR-0001: Record architecture decisions

- Status: Accepted
- Date: 2026-10-09

## Context
The project is long-lived and largely autonomous, and agents will help build it. Decisions need to stay discoverable and reviewable.

## Decision
Record significant decisions as numbered ADRs in `docs/adr/` (Nygard format). Breaking changes to public APIs or storage formats require an ADR.

## Consequences
Small overhead per decision. A durable rationale trail for future maintainers and for Whisipedia Living.
