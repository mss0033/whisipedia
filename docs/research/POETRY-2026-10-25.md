# Poetry sources (2026-10-25)

The owner asked for poetry beyond what the library holds. What it holds: Project Gutenberg tags
5,613 of its 79,576 books as poetry (4,182 English; then Finnish 387, French 244, German 177,
Portuguese 133); Wikisource in 11 languages holds single poems; the Text Creation Partnership
(EEBO, ECCO, Evans) holds early modern verse; Perseus (Greek and Latin) is a candidate. Modern poetry
is in copyright and out of reach of open sources.

Checked for each: licence from the publisher's own page, a bulk channel, and robots.txt for our
user agent (`Whisipedia/0.1 (personal offline archive)`).

| Source | What | Size | Licence | Channel | robots | Notes |
|---|---|---|---|---|---|---|
| **Eighteenth-Century Poetry Archive (ECPA)**, Bodleian | 3,728 works by 354 poets, TEI with form, rhyme and metre markup | small (XML) | CC BY-SA 4.0 (own texts) | GitHub `alhuber1502/ECPA`; per-work XML on the site | allows all but `/errors/` | Built on ECCO-TCP, corrected; overlaps TCP but better edited. |
| **Deutsches Textarchiv (DTA)**, BBAW | German 1600-1900, ~28k poems tagged Lyrik inside whole books | 361 MB core, 579 MB with extensions (TEI) | CC BY-SA 4.0 | `/media/download/*.zip` | allowed (per-book download paths are disallowed; the zips are not); Crawl-Delay 10 | Poetry is not a separate download: take the Belletristik zip, keep all. |
| **Ganjoor** | Classical Persian poetry: Rumi, Hafez, Saadi, Ferdowsi and some 200 poets | 114 MB SQLite (v3.1, 2026-09-25) | the poems are centuries old (public domain); the database states no terms of its own; the app is MIT | GitHub release asset `ganjoor/desktop` | GitHub | First-party release. Persian is translatable (fa is in the translator's list). |
| **Project Ben-Yehuda** | 20,000+ Hebrew public-domain works (Bialik, Tchernichovsky; poetry and prose) | release zip | public domain (stated) | GitHub `projectbenyehuda/public_domain_dump` | GitHub | First-party dump, with a catalogue CSV that has a genre field. |
| **Aozora Bunko** | Japanese public-domain literature incl. tanka, haiku, modern verse | ~4 GB git repo | public domain, some CC (catalogue flag) | GitHub `aozorabunko/aozorabunko` | GitHub | Keep only rows whose copyright flag is "none" (the repo also holds in-copyright works). |
| **chinese-poetry** | 55k Tang, 260k Song poems, 21k Song ci, Shijing, Chuci, Yuan qu | ~200 MB JSON | MIT (compilation) | GitHub `chinese-poetry/chinese-poetry` | GitHub | **Third party** ("collected from the internet", not logged): D17 applies. Cross-check against zh Wikisource's 全唐詩, which the library holds. |
| **OpenITI** (KITAB) | Classical Arabic corpus, incl. diwans | 5.8 GB | CC BY-NC-SA 4.0 | Zenodo | Zenodo | Mostly prose; poetry is a minor part. NC is acceptable (owner, 2026-10-18). Bigger than its poetry share warrants: optional. |

Not recommended:
- Poetry Foundation, Poets.org, Poem Hunter: in copyright, no bulk licence.
- PoetryDB, the Gutenberg Poetry Corpus: derived from Gutenberg, which the library has.
- Representative Poetry Online (Toronto): mixed copyright, no bulk channel; its canon is in
  Gutenberg and ECPA.
- cn-poetry.com: CC BY-NC, overlaps chinese-poetry.

Order proposed: ECPA, DTA, Ganjoor, Ben-Yehuda, Aozora (first-party, small, clear licences); then
chinese-poetry once D17's verifier can cross-check it; OpenITI only if wanted for Arabic in general.
